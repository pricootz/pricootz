# Pricop PowerPoint Tools

Native PowerPoint COM add-in for Windows.

## User installation
Run:
`PricopPowerPointTools-Setup.exe`

The installer:
- installs per-user, no admin required;
- registers the add-in for 32-bit and 64-bit PowerPoint;
- loads the `Pricop Tools` Ribbon tab automatically;
- installs custom icons;
- adds a normal Windows uninstaller.

## Stream Deck
Use native PowerPoint KeyTips:
- ALT, P, L — Align left
- ALT, P, C — Align center
- ALT, P, R — Align right
- ALT, P, T — Align top
- ALT, P, M — Align middle
- ALT, P, B — Align bottom
- ALT, P, H — Distribute horizontally
- ALT, P, V — Distribute vertically
- ALT, P, W — Same width
- ALT, P, E — Same height
- ALT, P, S — Same size
- ALT, P, Q — Rectangle
- ALT, P, A — Rounded rectangle
- ALT, P, O — Shadow off
- ALT, P, D — Shadow on
- ALT, P, N — Border off
- ALT, P, I — Border on
- ALT, P, F — Match style
- ALT, P, X — Clean boxes
